Features

Everything you need for global API monitoring

Enterprise-grade latency monitoring built for performance-obsessed teams

75+ Global Edge Locations

Monitor from the same locations as your users. Our edge network spans 6 continents with PoPs in major cloud regions including AWS, GCP, Azure, and Cloudflare.

Americas 18 regions
Europe 22 regions

Sub-Second Check Intervals

Run latency checks as frequently as every 100ms. Catch fleeting issues that 1-minute intervals miss. Perfect for high-frequency trading APIs and real-time applications.

Percentile Analytics

Go beyond averages. Track P50, P75, P90, P95, P99, and P99.9 latency percentiles. Understand your tail latency and outliers that impact user experience.

Smart Alerting

Set latency thresholds per region or globally. Get alerts via Slack, PagerDuty, OpsGenie, or webhooks. Suppress flapping with configurable cool-downs.

Multi-Region Comparison

Compare latency across regions side-by-side. Identify which edge locations need optimization. Track regional performance over time with trend analysis.

Historical Analysis

Store up to 2 years of latency data. Correlate performance changes with deployments. Generate SLA compliance reports for stakeholders.

API & Integrations

Full REST API access. Export metrics to Datadog, Grafana, Prometheus. CI/CD integration for automated performance testing in your pipeline.

SSL & DNS Monitoring

Track SSL certificate expiry and DNS resolution times. Get alerts before certificates expire. Monitor DNS propagation across regions.
